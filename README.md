## Contenido

| Archivo | Descripción |
|---|---|

## Modelo

Base de datos `ACTIVIDAD1` con las tablas: `SUCURSAL`, `EMPLEADO`, `DEPENDIENTE`, `CLIENTE`, `CUENTA`, `CUENTA_AHORRO`, `CUENTA_CORRIENTE`, `CLI_CUENTA`, `PRESTAMO`, `CLI_PRESTAMO` y `PAGO`.

## Uso

1. Abrir `EER DIAGRAM.mwb` con MySQL Workbench para ver el modelo.
2. Ejecutar `ACTIVIDAD1_SOLUCION.sql` en un servidor MySQL para crear la base, cargar datos de ejemplo y correr las consultas.

Los datos del script son ficticios.
